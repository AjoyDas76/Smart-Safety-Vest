# Project Persistent Rules & Constraints

## Strict User Directives
1. **NO BATTERY UI / METRICS**:
   - Never display or include any battery status, battery percentage, battery voltage, battery cards, battery chips, or battery tabs in any part of the user interface (Dashboard, Live Charts, Worker Cards, Status Banners, Map, etc.).
   - The user has explicitly and strictly commanded that all battery-related information must be excluded from the application UI.

2. **Distinct Sensor Colors**:
   - Temperature: Red / Coral (`#FF5252` / `#DC2626`)
   - Humidity: Cyan / Electric Blue (`#00E5FF` / `#0284C7`)
   - Pressure: Purple / Violet (`#A855F7` / `#7C3AED`)
